# Infrix DID context, version 1

This is the JSON-LD context named by every `did:infrix` DID document, at
`https://infrix.opendlt.org/ns/did/v1`. A client that asks for JSON-LD (an `Accept` header of
`application/ld+json` or `application/json`) receives the context document itself; a browser
receives this page.

The document is immutable. The version is in the URL: a change to any term is published as a new
version at a new URL, never as an edit of this one. Infrix core pins the SHA-256 of these exact
bytes and refuses a processor run against any other copy.

- Raw document: [v1.jsonld](/ns/did/v1.jsonld)
- SHA-256: `3394738e992a2d0409d286aa688ccbdba78bf7471ecd054baa0d54e653b627da`

It defines the terms the DID documents emit beyond the W3C DID core vocabulary:
`AccumulateKeyPage`, `keyPageUrl`, `keyBookUrl`, `pageIndex`, `threshold`, `CredentialRegistry`,
`LinkedData`, `InfrixContract`, `InfrixAPI` and `description`.
